# SISTEM PENGELOLAAN PENYEWAAN MOBIL PADA RENTAL MOBIL

## Deskripsi Proyek

ONE RENT merupakan aplikasi berbasis web yang dikembangkan untuk membantu admin dalam mengelola kegiatan operasional rental mobil. Sistem ini dirancang untuk mengintegrasikan proses pengelolaan data kendaraan, pelanggan, reservasi, transaksi penyewaan, pembayaran, pengembalian kendaraan, dan denda ke dalam satu aplikasi.

Dengan adanya sistem ini, proses pengelolaan data penyewaan diharapkan menjadi lebih terstruktur, sehingga admin dapat memantau informasi kendaraan dan menelusuri data penyewaan dengan lebih mudah.

## Tujuan Pengembangan

Pengembangan sistem ini bertujuan untuk mempermudah admin dalam melakukan pengelolaan administrasi rental mobil, mengurangi risiko kesalahan pencatatan, serta membantu pemantauan setiap tahapan proses penyewaan kendaraan.

## Fitur Sistem

Sistem ONE RENT memiliki beberapa fitur utama, yaitu:

1. **Dashboard** – Menampilkan ringkasan informasi pengelolaan rental mobil.
2. **Data Mobil** – Mengelola informasi kendaraan, termasuk data dan status ketersediaannya.
3. **Data Pelanggan** – Mengelola informasi pelanggan yang melakukan penyewaan.
4. **Reservasi** – Mencatat dan mengelola pemesanan kendaraan.
5. **Transaksi Sewa** – Mengelola transaksi penyewaan mobil.
6. **Pembayaran** – Mencatat pembayaran penyewaan dan pelunasan.
7. **Pengembalian** – Mencatat proses pengembalian kendaraan.
8. **Denda** – Mengelola denda apabila terjadi keterlambatan pengembalian kendaraan.
9. **Pengelolaan Admin** – Menyediakan fitur autentikasi dan pengelolaan akun admin.

## Teknologi yang Digunakan

Teknologi yang digunakan dalam pengembangan sistem ini meliputi:

- **Bahasa Pemrograman:** PHP
- **Basis Data:** MySQL
- **Lingkungan Pengembangan:** Laragon
- **Web Browser:** Google Chrome atau browser lainnya

## Cara Menjalankan Sistem

Untuk menjalankan aplikasi ONE RENT pada lingkungan lokal, langkah-langkah yang dilakukan adalah:

1. Pastikan Laragon telah terpasang pada komputer.
2. Simpan folder proyek `rental-mobil-ui` ke dalam direktori `C:\laragon\www`.
3. Jalankan Apache dan MySQL melalui Laragon.
4. Buat basis data MySQL dan impor file database yang tersedia pada folder proyek.
5. Sesuaikan konfigurasi koneksi database pada file `koneksi.php`.
6. Buka browser dan akses aplikasi melalui alamat lokal Laragon sesuai konfigurasi proyek.

## Ruang Lingkup Sistem

ONE RENT dikembangkan sebagai aplikasi berbasis web yang digunakan khusus oleh admin rental mobil. Sistem ini berfokus pada pengelolaan administrasi penyewaan kendaraan dan tidak mencakup layanan pemesanan mandiri oleh pelanggan, aplikasi mobile, maupun integrasi payment gateway.

## Status Pengembangan

Proyek ini dikembangkan sebagai bagian dari kegiatan Kerja Praktik dengan fokus pada perancangan, pembangunan, dan pengujian sistem pengelolaan penyewaan mobil berbasis web.
